### Hi, I'm Oliver 👋

I'm a Design Engineer at [utu design](https://www.linkedin.com/company/utu-design/), producing CAD site layouts for utility-scale solar and battery energy storage projects.

Alongside project delivery, I develop internal C#/.NET tooling for AutoCAD, including design automation, drawing analysis and workflow utilities used by the wider team. I also work with Python and JavaScript.

Most of my production tooling lives in private repositories. My two pinned public repositories are side projects built outside work:

* **[asciiwhatudidthere](https://github.com/nuageuk/asciiwhatudidthere)** — a real-time ASCII-art renderer for webcam and 3D scenes, running entirely client-side with Three.js and MediaPipe. [Live demo →](https://nuageuk.github.io/asciiwhatudidthere/)
* **[NuVec](https://github.com/nuageuk/NuVec)** — a Vectrex emulator written in C, including a custom Motorola 6809 CPU core, memory system and vector display. Currently in early development.
